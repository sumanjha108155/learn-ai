# learn-ai

A personal knowledge base for exploring, documenting, and comparing different AI tools — what they do, how to use them, and when they're actually worth reaching for.

## Why this repo exists

AI tools are shipping faster than anyone can keep track of. This repo is my running notes: setup guides, use-case breakdowns, prompt patterns, gotchas, and honest opinions on what's actually useful versus what's hype.

## Structure

```
learn-ai/
├── README.md
├── tools
└── resources/            # Articles, papers, courses worth revisiting
```

## How each tool doc is organized

- **What it is** — one or two lines
- **Use case** — what I actually use it for
- **Setup** — install/auth steps, API keys, quirks
- **Notes** — things I learned the hard way
- **Verdict** — worth it? for whom?
